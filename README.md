# Laserfiche Dashboard

Windows packages are published on the [Releases page](https://github.com/amjdKhaled/Asset-Manager-1zip/releases).
Use the artifacts attached to the current release or pull-request Windows build.
Legacy 1.0.4 binaries under `Release/` are retired; source ZIPs are not runnable installers.

- **LFDashboard-Setup.exe** upgrades the installed IIS application.
- **LFDashboard-Standalone-win-x64.zip** runs by double-clicking `Start-Dashboard.cmd`; no SDK or source build is needed.

See [offline previews and startup](docs/offline-preview.md) for supported formats and requirements.

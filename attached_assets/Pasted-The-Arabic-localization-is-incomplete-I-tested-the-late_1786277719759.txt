==================================================
JAVASCRIPT
==================================================

This is important.

Search JavaScript for hardcoded English strings.

Razor localization alone will NOT fix strings generated by JavaScript.

Do not leave things like:

"No data available"
"Loading..."
"Failed to load"
"Connected"
"Disconnected"

hardcoded in JS.

Expose the required localized strings from Razor to JavaScript safely.

For example create a JS localization object from Razor:

window.dashboardStrings = {
    loading: @Json.Serialize(L["Loading"].Value),
    noData: @Json.Serialize(L["NoData"].Value),
    connected: @Json.Serialize(L["Connected"].Value),
    disconnected: @Json.Serialize(L["Disconnected"].Value)
};

Then JS must consume those values.

Do not duplicate Arabic translations directly inside JavaScript.

User Permissions
==========================================================

The Dashboard must NEVER assume the Administrator user.

It must always use the currently logged-in Laserfiche user.

The statistics must respect Laserfiche security.

For example:

If User A has permission to see only:

HR
Training

then the Dashboard must calculate statistics ONLY from those accessible entries.

If User B has access to:

Finance
Contracts

then the Dashboard must automatically show statistics only for those folders.

No administrator privileges should ever be required.

Do not perform a second login using stored administrator credentials.

Reuse the active Laserfiche Desktop Client session whenever possible.

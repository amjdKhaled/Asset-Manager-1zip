User logs into Laserfiche

Laserfiche user A

Laserfiche user B
→ Dashboard must operate as user B
→ only user B's Laserfiche permissions apply.

Admin
→ Dashboard operates as Admin.

The Dashboard MUST NOT use one common account for everyone.

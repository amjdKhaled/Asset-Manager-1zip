ROOT CAUSE
==========

PowerShell variable names are case-insensitive.

$PID is a built-in automatic PowerShell variable containing the current
PowerShell process ID and is read-only.

Therefore any variable named:

$pid
$Pid
$PID

or a function parameter named:

param($Pid)

collides with the built-in $PID variable.

The failure occurs in Step 8 after WiX extensions are ready, most likely in
the New-HarvestWxs implementation or related generated WiX ID logic.

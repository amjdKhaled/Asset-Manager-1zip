GOAL 2 — SINGLE-FLIGHT TOKEN ACQUISITION
========================================================

Implement proper concurrency-safe token acquisition.

There must NEVER be multiple simultaneous token requests for the same:

    server + repository + credential identity

If 20 API requests arrive simultaneously and no valid token exists:

WRONG:

Request 1 → POST token
Request 2 → POST token
Request 3 → POST token
...
Request 20 → POST token

CORRECT:

Request 1 → acquire lock → POST token
Requests 2-20 → await same token acquisition

Then all 20 requests reuse the resulting token.

Use a proper per-cache-key asynchronous single-flight mechanism.

For example:

ConcurrentDictionary<string, SemaphoreSlim>

or a cached Task<Token>

but implement it safely.

Required algorithm:

GetTokenAsync(cacheKey):

    check cache

    if valid token exists:
        return immediately

    acquire async lock for cacheKey

    check cache AGAIN after acquiring lock

    if another request already refreshed token:
        return it

    request ONE token

    cache token with expiration

    release lock

Do NOT use Thread.Sleep.
Do NOT use synchronous locks around async code.
Do NOT create a global lock unnecessarily across different repositories.

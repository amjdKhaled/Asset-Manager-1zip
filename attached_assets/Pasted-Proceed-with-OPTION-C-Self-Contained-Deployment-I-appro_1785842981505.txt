Proceed with OPTION C: Self-Contained Deployment.

I approve keeping LFPortal.Web on ASP.NET Core / .NET 8.

DO NOT port the web application to .NET Framework 4.8.

Primary objective:

The Dashboard must carry its own .NET runtime and must not depend on a separately installed .NET 8 runtime.

Implement this production-safely.

==================================================

A. Missing .NET 8 runtime
B. Missing ASP.NET Core Module V2

A must NOT block installation anymore.

B MUST still be detected because IIS requires ANCM to host the Dashboard.

Do NOT install/uninstall/change Laserfiche runtimes.

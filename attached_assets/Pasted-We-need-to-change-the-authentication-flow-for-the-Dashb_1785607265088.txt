7. LOGIN VALIDATION
==================================================

When Sign In is clicked:

1. Read active repository from IRepositoryContext/session.
2. Read Username.
3. Read Password, allowing "".
4. Attempt real Laserfiche authentication.
5. Confirm access to the active repository.
6. Only if authentication succeeds:
   - establish credentials for the current session/repository
   - mark session authenticated
   - redirect to Dashboard.

If authentication fails:

Stay on Login.

Display a clean error such as:

"Unable to sign in to TestEmployee. Check the username and password."

Do NOT expose:

stack traces
Bearer tokens
raw Laserfiche API responses
internal exception details

CURRENT PROBLEM:

The installer asks for Repository ID.

This is wrong for the intended design.

The Dashboard is launched from Laserfiche and must operate against the
repository/session context of the Laserfiche user who opened it.

Repository ID must NOT be permanently selected during installation.

For example:

User opens Laserfiche Desktop Client:

Repository: TestEmployee
User: admin

Then opens Dashboard.

Dashboard should use:

Repository = TestEmployee
Current Laserfiche user/context

If another user opens:

Repository: Master
User: Ahmed

Dashboard should use Master instead.

============================================================
PER-SESSION TOKEN ISOLATION
============================================================

Audit all token caching.

This is critical.

A token must NEVER be globally cached only by repository ID if multiple users
can access the Dashboard.

Bad:

TokenCache["NewEmployeeTest"] = adminToken

Then Khaled opens NewEmployeeTest and accidentally receives adminToken.

Correct concept:

TokenCache[
    DashboardSessionId,
    RepositoryId,
    UserIdentity
]

or another secure per-session isolation design.

User A must never reuse User B's Laserfiche token.

Repository switching must also invalidate or select the correct token.

Logout/session expiration must remove the corresponding token.
